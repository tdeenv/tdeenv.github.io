Tableau Data Viz GIS

Mapping Sydney's Data

2024

As I continue learning Tableau, I've been diving into features like calculated fields, parameters, and parameter controls to build interactive visualisations. This project focused on using shapefiles to create detailed and dynamic maps of Sydney.

The dashboard below lets you explore social datasets across Sydney's local government areas, with parameter controls to switch between views.

// interactive dashboard

What I learned

Building this pushed me to get comfortable with Tableau's geographic features, particularly around loading custom shapefiles. Parameter actions are a powerful way to make dashboards feel responsive without writing any code.
